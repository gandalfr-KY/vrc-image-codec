# VRC AVIF Codec

Independent single-image AVIF encoder and matching decoder for Unity 2022.3 / VRChat Worlds SDK 3.10.5 or later. BSD-2-Clause; upstream attribution and the AOM patent grant are in ThirdParty/AV1 and PATENTS.

## Install

Import the generated unitypackage, or put this package in `Packages/com.gandalfr.vrc-avif`. Use **Tools → AVIF Encoder → Create encoder**. The tool creates the component, compiled Udon programs and working RenderTextures. The VPM archive contains the same source; no native plug-in is required. VCC listing publication is a separate release step.

## API

Both components advance automatically in their own `Update`. Call Begin once and observe completion; do not also call Step every Update. Step is exposed for a caller that deliberately owns scheduling instead of the component's Update.

| Operation | Encoder | Decoder |
| --- | --- | --- |
| Component | `TernaryAvifEncoder` | `TernaryAvifDecoder` |
| Input | `gpuTransform.inputTexture` | `inputAvif` (`byte[]`) |
| Start | `BeginEncoding()` | `BeginDecoding()` |
| Explicit step | `StepEncoding()` | `StepDecoding()` |
| Cancel | `CancelEncoding()` | `CancelDecoding()` |
| Result | `resultAvif` (`byte[]`) | `resultTexture` (`RenderTexture`) |
| State | `busy`, `complete`, `error`, `progress` | `busy`, `complete`, `error`, `progress` |

Render into `encoder.gpuTransform.inputTexture`, then call `encoder.BeginEncoding()`. When `complete` is true, pass `encoder.resultAvif` to `decoder.inputAvif` and call `decoder.BeginDecoding()`. When decoding completes, assign `decoder.resultTexture` to your display material. Create a configured decoder using **Tools → AVIF Encoder → Create decoder**. Check `error` when an operation ends without completion.

Keep input bytes unchanged while decoding. The decoder owns its output RenderTexture and reuses it on the next decode; copy it with a GPU blit if a previous image must be retained. Cancel clears the public result/state but keeps GPU allocations for reuse. After cancelling an encode, wait until `gpuEntropy.readbackPending` is false before starting again. All state is local.

Editor code can call `VrcAvif.Encoder.Editor.AvifEncoderSetup.Configure(encoder, width, height, quality, load)`. Settings are validated there. Width and height must be multiples of eight, 16–1920, with at most 2,073,600 pixels. Default: 640×360, quality 60, 4:2:0. Quality changes coding quality; load changes scheduling only. AVIF output is capped at 100,000 bytes.

The matching decoder scheduling API is `AvifEncoderSetup.Configure(decoder, load)`. Both accept `AvifProcessingLoad.Gentle`, `Normal` and `Fast`. Encoder GPU diagonals per frame are 2/4/8; decoder reconstruction diagonals are 4/8/16, with soft decoder CPU budgets of 1/2/4 ms. `Fast` reduces frame scheduling waits at a higher per-frame cost; it does not change quality or the AVIF bitstream. Normal remains the default. There is no CPU encoding budget because encoding no longer traverses coefficients on Udon.

Adaptive CDF updates are always enabled. The experimental frozen-CDF encoder option and CPU entropy-coder path are removed.

The encoder GPU performs prediction, transform, quantization, coefficient traversal, syntax generation, all CDF updates, range coding and AVIF assembly. `TernaryAvifEncoder` coordinates the transform and `TernaryAvifGpuEntropy`; the latter owns intermediate textures and asynchronous readbacks. There is no coefficient readback or CPU-to-GPU symbol upload. A 4-byte record count returns to Udon to size working textures; the final readback returns the complete AVIF in a padded buffer. Udon allocates the result byte array and copies the completed bytes. Fixed probability tables and container templates are generated by the Editor during configuration, not per photograph. Quality changes are applied to the AVIF header on the GPU.

The decoder still parses headers and entropy-decodes on Udon, uploads packed coefficients once, and reconstructs/predicts/filters on the GPU without a production GPU readback. Its `frameBudgetMs` is a soft CPU budget; allocation and GPU submission may exceed it. `diagonalsPerFrame` controls decoder reconstruction scheduling. The encoder requires PC shader model 5.0 and floating-point RenderTextures.

For an existing encoder, run `AvifEncoderSetup.Configure(...)` once after upgrading. It adds/configures `gpuEntropy`, its three ordinary shaders and initial/header textures. Existing script GUIDs and the documented Begin/Step/Cancel/result API are retained. Diagnostic encoder fields `frameBudgetMs`, `entropySeconds`, `modeCounts` and the transform's old coefficient `result`/`readbackPending` are removed; consumers waiting for encoding readbacks should use `gpuEntropy.readbackPending`.

The decoder accepts this encoder's restricted still-image profile, not general AVIF from arbitrary software: 8-bit SDR, 4:2:0, fixed 8×8 luma / 4×4 chroma transforms, one image, one tile, known headers, at most Full HD and 100,000 bytes. Unsupported headers fail through `error`. Alpha, HDR, animation, other block layouts and arbitrary libaom output are outside this API. RGB output is sRGB with nearest chroma upsampling; YUV reconstruction is independently checked against FFmpeg.

There is no JPEG fallback, network call, URL handling, encryption, synchronization or storage dependency. Class names, package ID and existing asset GUIDs are retained so scenes can resolve moved scripts.

## Minimal camera example

Copy Samples~/MinimalCamera into Assets. Add MinimalAvifCapture alongside the encoder and assign its Camera and encoder fields. Render a frame using Capture(), then wait for the encoder result. The example has no pickup or UI; custom camera models and capture controllers stay outside this library.

## Verification and releases

`python Tools~/check-codec.py <isolated-unity-project> --prepare` prepares the actual compiled-Udon/GPU encoder suite. Refresh Unity, request it with `--run`, then run without flags to verify all reference bytes and independent FFmpeg decoding. It covers portrait/Full-HD fixtures, all probability-context families, cancellation/reuse, invalid quality and a full capture. No CPU codec mock replaces GPU processing. See Tests~/README.md. `python Tools~/check-decoder.py` checks production entropy decoding against every recorded coefficient, cancellation/reuse, adaptive/frozen probability models and malformed inputs using Mono C#. On Windows, `python Tools~/check-shaders.py` compiles all production shader entrypoints with D3DCompiler.

`python Tools~/pack.py` creates a VPM package zip and GUID-preserving unitypackage under release/. Tests, build tools and optional samples are excluded from the installed package; the sample is included separately in the zip under Samples~.
